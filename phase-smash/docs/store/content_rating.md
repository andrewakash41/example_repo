# Content rating questionnaire — answer sheet

Answers for the IARC content-rating questionnaire in the Play Console. Phase
Smash is an abstract arcade game with no objectionable content; expect an
**Everyone / PEGI 3 / 3+** rating. Confirm each answer as worded at submission.

## Category

- App category: **Game**.

## Violence

- Realistic or cartoon violence? **No.**
- Depictions of blood/gore? **No.**
- (Segments "shatter" — abstract geometric breakage, no characters harmed.)

## Sexuality / nudity

- Any sexual content or nudity? **No.**

## Language

- Profanity or crude humor? **No.**

## Controlled substances

- References to drugs, alcohol, tobacco? **No.**

## Gambling

- Simulated gambling / real-money gambling? **No.**
- (Crates are earned through play and rewarded ads only; **no purchase, no
  real-money loot boxes** at launch. If IAP is added later, re-answer.)

## User interaction / data

- Users can interact (chat/UGC)? **No.**
- Shares user location? **No.**
- Digital purchases? **No** (at launch).

## Ads

- Displays ads? **Yes** (interstitial + rewarded via AdMob, at natural breaks).
