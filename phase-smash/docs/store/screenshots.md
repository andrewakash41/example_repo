# Screenshots & video — capture checklist

Play requires ≥2 phone screenshots (we target **≥6**) plus an optional promo
video. These must be captured from the running game, so this is a **device/editor
task** — the shot list below is prepared; capture once the game runs.

## Requirements

- Phone screenshots: PNG or JPEG, 16:9 or 9:16, min 320px, max 3840px per side.
  Portrait (our orientation) at the device's native resolution is ideal.
- Feature graphic: 1024×500 — export `assets/store/feature_graphic.svg` to PNG.
- App icon: 512×512 — export `assets/store/icon_512.svg` to PNG.
- Promo video (optional): ~30s gameplay capture, upload to YouTube, link it.

## Shot list (capture these 6+)

1. **Core smash** — mid-dive, phase ring near a flip, combo multiplier visible.
2. **Phase decision** — ball one color, an opposite-color band just ahead
   (shows the central mechanic).
3. **Fever** — white-hot ball, flame trail, FOV kick, high combo.
4. **Boss tower** — gold rim grade, the two counter-rotating bands.
5. **Level clear** — confetti + score tally + crate progress.
6. **Meta** — skins gallery (a couple unlocked) or the pre-level booster slots.

Optional 7. Home screen with the title + PLAY.

## How to capture

- In the Godot editor: run the game, use the OS screenshot tool at a portrait
  window size (e.g. 1080×1920), or run on a device and use device screenshots.
- For the video: screen-record a 30s run that hits smash → fever → boss → clear.

## Framing

- Keep the HUD readable; avoid capturing during the flip flash.
- Use a couple of different themes across the 6 shots for visual variety.
